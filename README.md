# Curatio for Unraid

Community Applications template for [Curatio](https://curatio.tv): personal recommendations and a great player for the movies and shows you already have on Plex or Jellyfin.

**Install:** on the Unraid **Apps** tab, search for **Curatio** and click **Install**. Fill in Base URL, TMDB API key and Admin password, then put it behind your reverse proxy with HTTPS.

The full guide is at [github.com/curatio-app/curatio](https://github.com/curatio-app/curatio#unraid).

| File | What it is |
|---|---|
| `templates/curatio.xml` | The container template (image `ghcr.io/curatio-app/curatio:aio`, database built in) |
| `ca_profile.xml` | Maintainer profile for Community Applications |

Problems: [open an issue](https://github.com/curatio-app/curatio/issues).
